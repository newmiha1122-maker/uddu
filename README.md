# RFTL Transfer Center — MVP

Первая рабочая версия Telegram-бота: анкеты игроков, модерация, лента свободных игроков, приглашения клубов и базовый список трансферных предложений.

## 1. Создай бота
1. Открой Telegram и найди `@BotFather`.
2. Выполни `/newbot` и скопируй токен.
3. Узнай свой Telegram ID у бота `@userinfobot`.

## 2. Загрузи проект на GitHub
Распакуй ZIP и загрузи все файлы в новый GitHub-репозиторий.

## 3. Запусти на Railway
1. Создай новый проект Railway из GitHub-репозитория.
2. Добавь Variables:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_IDS` — твой Telegram ID (если админов несколько, перечисли через запятую)
   - `DB_PATH` — `rftl.db`
3. Убедись, что Railway запускает сервис как Worker. Procfile уже содержит `worker: python main.py`.
4. Для постоянного хранения базы SQLite добавь Railway Volume и подключи его к сервису, например в `/data`, затем выставь `DB_PATH=/data/rftl.db`.

## Команды
- `/start` — открыть бота
- `/apply` — отправить анкету игрока
- `/myprofile` — посмотреть анкету
- `/registerclub Название` — зарегистрировать клуб
- `/market` — лента одобренных игроков (для менеджеров)
- `/invitations` — приглашения
- `/transfer_offer` — создать трансферное предложение
- `/moderation` — очередь анкет (админы)
- `/approve ID` и `/reject ID` — решение по анкете
- `/setmanager USER_ID Название клуба` — назначить менеджера (админы)
- `/pending_transfers` — очередь трансферов (админы)
- `/transfer_decide ID approve|reject` — решение по трансферному предложению (админы)

## Важно
- Рейтинг проверяется на сервере и должен быть в диапазоне 1.0–7.0, включая дробные значения.
- Анкеты не попадают в ленту, пока администратор их не одобрит.
- Игроку можно отправить личное приглашение только после того, как он запустил бота хотя бы один раз.
- Это MVP. Следующий этап — кнопочная модерация, фильтры ленты, редактирование/скрытие анкет, корректный двусторонний процесс трансфера и Mini App.
